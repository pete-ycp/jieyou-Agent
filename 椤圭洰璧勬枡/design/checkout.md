# 确认订单 `/checkout` — checkout.md

> 气质：柜台前的一张牛皮纸订单——「包裹将从浪矢杂货店寄出」。

## Section 1 · 步骤指示

顶部居中三段木牌步骤条：① 点货（已完成，朱红章）→ ② 写收货地址（当前，暖黄底）→ ③ 柜台结账（未至，灰）。木牌间手绘虚线连接。
**Animation**：进入时当前步木牌微亮呼吸一次（800ms）。

## Section 2 · 双栏（左表单 7 : 右摘要 5，移动竖排）

**左 · 收货信息（牛皮纸大卡）**：
- 标题 H3「包裹寄往哪里？」
- 已存地址：横排地址卡列表（单选，选中=朱红双线描边+「常用」小章），「+ 新地址」卡（虚线框）
- 新地址表单：收件人 / 手机号 / 省市区一行 / 详细地址（多行）/「存为常用地址」勾选章。所有输入框=信纸风（透明底 + 底部 1px 手划线，聚焦时线变朱红并轻微加粗，label 上浮 12px）
- 校验失败：字段下苔绿小字提示（不用红色报错，用「这一格还没写好」语气）
**Animation**：表单字段 stagger 0.06s 入场（y 16→0, 500ms）；地址卡选中=章盖下动效（scale 1.3→1, 250ms）。

**右 · 订单摘要（sticky top 100px）**：
- 标题 H3「篮子里这些」
- 商品快照清单（图 56px + 名 + ×n + 小计，EB Garamond）
- 缝纫虚线 → 商品合计 / 运费（「店主骑车送 · 包邮」苔绿）/ 应付合计（EB Garamond 28 邮戳朱）
- 主 CTA「提交订单，去柜台结账」（邮戳朱块级）
- 下方小字氛围文案：「包裹会用牛皮纸包好，从浪矢杂货店寄出。」
**Animation**：摘要卡入场 slide-right 40px→0（700ms）；合计在地址填写完成前以 60% 透明度呈现，表单合法后 300ms 提亮。

## 提交后行为
- 生成订单（状态=待支付）→ 跳转 `/pay/:orderNo`。
- 提交中 CTA 变「正在写订单…」+ 钢笔 icon 微动（防重复点击）。
- 本页无图片资产需求（纯纸感组件）。
