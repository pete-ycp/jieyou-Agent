# 信件/回信阅读 `/letters/:id` + 感谢信 `/letters/:id/thanks` — letter-detail.md

> 仪式感顶峰页：像从牛奶箱里抽出一封真的信，在台灯下展开读。

## 阅读页 `/letters/:id`

### Section 1 · 进入动效（页头即动效）
**Layout**：720px 单列，深夜氛围 + 顶部一团台灯暖光。
**Animation**：整页 = 一次 `<PaperUnfold/>`：信纸 scaleY 0.6→1 摊平（900ms）→ 邮戳盖章（scale 1.6→1, rotate -12°→-8°, 400ms + 墨晕）。之后不再循环。

### Section 2 · 来信（你的信）
**Layout**：`<LetterPaper/>` 大卡：
- 卡头：分类印章 + 笔名落款（手写体 H3「——{笔名}」）+ 右上角投信日期邮戳（真实日期）
- 正文：Noto Serif SC 17/32，行距对齐信纸横线，段落首行缩进 2 字
- 卡右下角分类小字（「爱情 / 梦想 / 家庭 / 事业 / 人生方向」其一）
**Animation**：正文随展开动效后逐段浮现（stagger 0.2s, opacity only, 慢）。

### Section 3 · 回信（店主的信）——三种状态
**状态 A · 待回信**：来信下方一张窄卡：台灯 icon 呼吸 +「店主正在认真读你的信。回信会在 {预计时间} 前放进牛奶箱。」+ 倒计时。
**状态 B · 已回信**：第二张 `<LetterPaper/>`（色调略暖一档以示区分）：
- 抬头「{笔名} 收：」正文落款手写体「浪矢杂货店」+ 回信日期邮戳
- 回信末尾固定一行手写体小字（SOP 收尾）：「一切全在你自己。」
**状态 C · 白纸彩蛋**：回信=预置彩蛋信（同 letter-new §7 文案），卡角苔绿「彩蛋」小签。
**Animation**：回信卡进入视口时再播一次缩版 `<PaperUnfold/>`（700ms）；落款「浪矢杂货店」最后以手写描边 draw 效果出现（800ms）。

### Section 4 · 回信后动作条
- 「把这封回信分享给需要的人」：生成分享卡（1080×1350：信纸底 + 回信金句节选 + 店名 + 二维码位）
- 满 7 天：浮现感谢信邀请卡（苔绿描边）：「后来怎么样了？给店主写封感谢信吧。」→`/letters/:id/thanks`
- 已写感谢信：展示第三张小信纸（感谢信 + 日期邮戳 + 「店主已读」小章）
**Animation**：动作条入场 y 24→0（600ms, trigger 85%）。

## 感谢信页 `/letters/:id/thanks`

**Layout**：与写信页同构的简化版（无分类、笔名沿用原信）：窄信纸编辑器，placeholder「告诉店主，后来怎么样了……」+ 提交「投进投递口」（复用 `<EnvelopeDrop/>` 缩版 1.2s）→ 成功态「感谢信已送到店主桌上。」+ 返回我的信件。
**提示条**：「感谢信若被店主精选，会先脱敏、经你允许后才可能出现在示例信件墙。」
**Animation**：同 letter-new 编辑器规范。

## 交互备忘
- 全部接口属主校验；未登录/非本人 → 重定向。
- 彩蛋信也走本页（状态 C），支持分享。
- 本页无新增图片资产（邮戳/信纸均为组件）。
