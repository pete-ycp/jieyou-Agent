# 店主工作台 `/admin/*` — admin.md

> 角色：admin 专属（非 admin 403）。气质：**"店主的后间"**——与前台同一世界观但更重效率：保留纸感与暖色，弱化装饰动效（入场动效≤400ms，无循环氛围动效，除回信工作台的台灯）。
> 布局：左侧木棕窄侧栏（220px，移动折叠为顶部抽屉）+ 右侧内容区。侧栏项：货架管理 / 回信工作台（带待回数角标，超时数朱红角标）/ 订单柜台 / 内容架 / 回前台。

---

## A. 货架管理 `/admin/products`

**Layout**：顶部工具条（「+ 上架新商品」邮戳朱主钮 + 分类筛选 + 状态筛选 在售/下架 + 搜索框）+ 商品表格卡（牛皮纸底，双线表头）：
- 列：缩略图 56px / 名称 / 分类小签 / 价格(EB Garamond) / 库存（<10 苔绿警示，=0 褪朱红「售罄」）/ 状态（在售=苔绿章，下架=灰章）/ 操作（编辑 · 上下架 · 删除）
- 编辑/新建：右侧 Drawer 表单（名称/分类下拉/价格/库存/主图上传/详情富文本/店主手记 textarea——手记字段带手写体预览区）+ 保存后前台实时生效
**Animation**：表格行 stagger 0.04s（y 12→0, 350ms）；Drawer x 100%→0（400ms）；上下架切换=章盖下（250ms）。
**校验**：价格/库存非法值拒绝 + 苔绿行内提示；删除二次确认（「这件要从货架上撤掉吗？」）。

## B. 回信工作台 `/admin/letters`（全站运营核心）

**Layout**：三栏（lg）：左=待回队列（320px）｜ 中=来信+回信编辑器（弹性宽）｜ 右=**SOP 常驻侧栏**（280px，见下）。移动折叠为 Tab 切换。

**左 · 待回队列**：
- 按投信时间正序（最早在最上）；每项：笔名（手写体）+ 分类印章小章 + 投信时间 + 剩余时限条（暖黄进度条，<4h 变褪朱红）
- **超时 24h：置顶 + 朱红描边 + 「超时」章**；Tab 筛选（待回 / 已回 / 感谢信 / 彩蛋记录）
**中 · 回信区**：
- 上=来信 `<LetterPaper/>` 只读卡（分类印章 + 笔名 + 日期邮戳 + 全文）
- 下=信纸式回信编辑器（同前台编辑器皮肤）+ 落款固定「浪矢杂货店」不可改 + 「放入牛奶箱」邮戳朱主钮
- 发布成功：盖「已入牛奶箱」章（500ms）→ 队列自动取下一位
- 感谢信 Tab：可标记精选（弹确认：「将脱敏后展示到示例信件墙，已隐去一切身份信息？」→ 进入内容架待发布）
**右 · SOP 常驻侧栏**（牛皮纸卡，标题「回信的规矩」+ `admin-lamp.png` 小图 + 台灯呼吸光晕——后台唯一循环氛围动效）：
1. 绝不无视任何一封信——包括测试信与恶作剧信
2. 不替对方做决定：咨询的人心里已经有了答案
3. 先共情，后建议：先复述确认处境，再给方向
4. 宁可慢，不可敷衍
5. 保护匿名，不窥探身份；结尾把选择权交还对方（「一切全在你自己」）
**Animation**：队列入场 stagger 0.06s；选中信件=编辑器纸面展开缩版（500ms）；超时卡有 3.2s 朱红微脉冲（责任提示，允许）。

## C. 订单柜台 `/admin/orders`

**Layout**：状态 Tab（全部/待支付/待发货/已完成/已取消 + 计数）+ 订单表格卡：订单号(EB Garamond) / 用户笔名 / 商品摘要 / 金额 / 收货信息（点击展开行）/ 状态章 / 操作（待发货→「寄出」主钮；其他→详情）
- 「寄出」操作：确认 Drawer → 盖「已寄出」章 → 状态同步前台用户端
- 详情 Drawer：订单存根（复用前台 `/orders/:id` 排版）+ 操作留痕（回文人/发货人、时间戳列表）
**Animation**：同行表格规范；「寄出」盖章 400ms。

## D. 内容架 `/admin/content`

**Layout**：三 Tab（语录 / 示例信件 / 关于页文案），统一列表+Drawer 编辑：
- 语录：正文 + 出处章节 + 排序号 + 上下线开关（章形 toggle）
- 示例信件：笔名/分类/来信正文/回信正文/插画选择/化名故事标注（强制勾选「已确认为原创改写」才能上线）
- 关于页：分幕文案块编辑
**Animation**：同 A 规范。

## 全局备忘
- 后台路由双重鉴权（前端守卫 + 接口 admin 校验），非 admin 403。
- 后台无需新增图片资产，仅 `admin-lamp.png`；组件全部复用前台纸感体系（表格用简化双线样式）。
- 所有写操作留痕（操作人+时间），展示于各详情 Drawer 底部「柜台账本」区。
