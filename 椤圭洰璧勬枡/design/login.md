# 登录 `/login` — login.md

> **用户已确认：Kimi 登录（OAuth 一键登录，首次登录自动开户）——无注册页、无密码表单。** 气质：一张摊在木桌上的信笺，"先进店来，写不写随你"。

## Section 1 · 单屏居中（100vh，无多余区块）

**Layout**：bg-cream + 纸噪点。中央 480px 大卡（竖构图，`login-letter.png` 作卡内背景插画或纯牛皮纸卡均可，插画版优先）：
- 卡顶：`<ShopSign/>` 小招牌 + 手写体 H1「进店来」
- 小字：「写信、买东西，都从这个门进。第一次来？门会自动为你开。」
- 缝纫虚线
- 主按钮（块级，邮戳朱，带 Kimi 标识）：「用 Kimi 一键进店」
- 下方两行小字（Caption，青灰）：
  - 「首次登录将自动为你开户，无需注册。」
  - 「解忧信件只需笔名，本店绝不打听你是谁。」
**Animation**：卡入场 `<PaperUnfold/>`（scaleY 0.7→1, 900ms）；主按钮延迟 400ms 浮入（y 16→0）+ 常驻朱红呼吸；卡上邮戳在载入 1.2s 后盖下「欢迎咨询」小章（scale 1.4→1, 400ms）。

## 交互与状态
- 携带 `?from=` 参数：登录成功回跳来源页（写信/购物车/订单等受保护页）。
- 点击主按钮 → Kimi OAuth 授权页；回调成功 → Toast 纸笺「门开了，请进。」→ 回跳。
- 授权失败/取消：卡上浮现苔绿提示条「门还没开，再敲一次？」，按钮恢复可点。
- 已登录访问本页：直接重定向 `from` 或 `/`。
- 管理员（admin 角色）登录后导航出现「店主工作台」入口，无单独登录页。
- 本页 Assets：`login-letter.png` `logo-sign.svg`（复用组件亦可）。
