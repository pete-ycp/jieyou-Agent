# 我的订单 `/orders` + 订单详情 `/orders/:id` — orders.md

> 气质：柜台上按日期码放的一沓订单明信片。

## 列表页 `/orders`

### Section 1 · 页头 + 状态 Tab
- 手写体 H1「我的订单」+ 小字「每一笔，柜台都记着。」
- 状态 Tab（全部 / 待支付 / 待发货 / 已完成 / 已取消）：木牌 Tab，选中=暖黄底 + 朱红手划下划线（Framer Motion layoutId 滑动 300ms）。Tab 右侧 EB Garamond 计数。
**Animation**：页头 y 30→0（600ms）。

### Section 2 · 订单卡片列
每订单=一张横式明信片大卡：
- 卡头行：订单号（EB Garamond）+ 下单日期邮戳小章 + 状态章（待支付=暖黄「待结账」/ 待发货=苔绿「店主备货中」/ 已完成=青灰「已寄达」/ 已取消=灰「已作废」）
- 卡体：商品快照行（图 64px + 名 + ×n，超过 3 条折叠「等 N 件」）
- 卡脚：合计（EB Garamond 22 邮戳朱）+ 操作钮（按状态：待支付→「去柜台结账」主 + 「取消订单」文字链；待发货→「查看详情」；已完成→「查看详情」+「再买一单」；已取消→仅详情）
**Animation**：卡片 stagger 0.08s（y 32→0, 700ms）；取消订单=先弹纸感确认 Drawer（「这单就不要了？」）→ 卡上盖「已作废」灰章（rotate -6°, 400ms）原位变灰，不移除。

### Section 3 · 空状态
`product-placeholder.png` + 「柜台上还没有你的订单。」+ 主 CTA「去货架看看」+ 次链「写一封信 →」。
**Animation**：同 cart 空态规范。

## 详情页 `/orders/:id`

**Layout**：720px 单列，一张大牛皮纸"订单存根"卡：
- 顶部：状态大字章（按状态色）+ 订单号 + 日期邮戳
- 状态时间线（竖排步骤条）：写订单 → 柜台结账 → 店主备货 → 寄出，已完成节点朱红章 + 时间，当前节点暖黄呼吸点
- 缝纫虚线 → 商品快照清单（图 72px + 名 + 单价 + ×n + 小计）
- 缝纫虚线 → 收货信息块（收件人/电话/地址，信纸风排版）
- 缝纫虚线 → 金额块（商品合计/运费「店主骑车送」/实付 EB Garamond 28）
- 底部操作（同列表状态逻辑）+ 氛围行：「包裹从浪矢杂货店寄出 · 随附一张解忧卡片」
**Animation**：整卡纸面展开（scaleY 0.7→1, 800ms）；时间线节点自上而下逐个盖章（stagger 0.2s）；金额数字滚入（400ms）。
