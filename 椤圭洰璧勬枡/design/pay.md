# 模拟支付 `/pay/:orderNo` — pay.md

> 气质：小店柜台。一页两态：① 收银台（待支付）② 支付成功（包裹寄出）。演示环境不接真实支付网关。

## 状态 A · 收银台

**Layout**：居中 560px 牛皮纸大卡（邮柜台面隐喻）：
- 顶部：手写体 H1「柜台结账」+ 小字「演示柜台 · 不会真的收你的钱」（Caption，苔绿）
- 订单摘要：订单号（EB Garamond，如「NAMIYA-20240613-0007」）+ 下单时间 + 商品行压缩列表 + 缝纫虚线 + 应付金额大字（EB Garamond 36 邮戳朱「¥ 256.00」）
- 支付方式：单选卡×2——「柜台现金（模拟）」（默认选中，铜钱 icon）/「街口银行转账（模拟）」——仅样式差异，均为模拟
- 按钮组：主 CTA「付款」（邮戳朱，宽 60%）+ 次「先不付了」（文字链，→`/orders`，订单保持待支付）
**Animation**：卡入场 scaleY 0.7→1 纸面展开变体（800ms）；金额数字逐位滚入（500ms）；「付款」按下后进入 1.2s 模拟处理（卡中央墨点晕开转圈）→ 盖章「已收款」朱红大章（scale 1.8→1, rotate -10°, 500ms + 墨晕扩散）→ 400ms 后切换状态 B。

## 状态 B · 支付成功（本页核心情绪）

**Layout**：同卡翻转/替换为成功态：
- 朱红「已收款」邮戳章居上（常驻微斜 -8°）
- 手写体 H1「付好了。」
- 正文：「包裹会用牛皮纸包好，从浪矢杂货店寄出。店主还会随包裹附上一张解忧卡片——如果你刚好有心事。」（氛围文案，不承诺实物）
- 状态时间线：已收款（朱红章）→ 店主备货中（当前，暖黄呼吸点）→ 寄出（灰）
- 双 CTA：主「查看我的订单」→`/orders`；次「写一封信给店主」→`/letters/new`（商城-信箱联动，邮戳朱描边）
**Animation**：成功章盖下（500ms）后文案 stagger 0.12s 浮现；时间线当前节点暖黄呼吸常驻；双 CTA 延迟 600ms 浮入。

## 边界
- 非本人/不存在订单：重定向 `/orders` + Toast「这张订单不在你的柜台上」。
- 已支付订单再访问本页：直接显示状态 B。
- 取消：不弹确认，直接回 `/orders`（Toast「订单先放在柜台上，随时回来付」）。
- 本页无图片资产；邮戳章用 SVG 组件。
