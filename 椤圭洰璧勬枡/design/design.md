# 「解忧杂货店」网站 · 全局设计文档

> 依据：`/mnt/agents/output/解忧杂货店网站-需求文档.md`（PRD V1.0）第 8 章视觉规范 + 用户已确认方向。
> **与 PRD 的一处偏差（用户澄清覆盖）**：登录采用 **Kimi 登录（OAuth 一键登录、自动开户），无独立注册页**；PRD 中的 `/register` 取消，账户页仅保留 `/login` 与 `/profile`。其余均遵循 PRD。
> 技术栈：Node.js 20 · React 19 + TS · Tailwind CSS v3.4 · shadcn/ui · GSAP + ScrollTrigger · Framer Motion · Lenis。

---

## 0. 设计总纲（一句话）

> 「像深夜误入一条上坡小街尽头的老杂货店：卷帘门半掩、招牌字迹黯淡，店内一盏暖黄台灯下摊着信纸。」——全站所有视觉与动效决策都服务于这一句氛围文案。

三条不可妥协的设计原则：
1. **纸与木的世界**：没有一块纯平纯色面。所有表面带和纸/牛皮纸纹理 + 极轻噪点，结构件用深木棕木纹。
2. **慢，是尊重**：全站动效 ease-out ≥400ms，拒绝弹跳（no spring/bounce）。灯的呼吸、信封投递、纸面展开都要"像真实世界一样慢半拍"。
3. **商城是货架，信箱是灵魂**：商城走完整电商流程但保持"街角小店精选货架"气质（少 SKU、店主手记、无促销大卖场感）；信箱板块承担全部情绪峰值（投递动效、牛奶箱开启、信纸阅读）。

## 3. 材质与图形语言

### 3.1 纹理（全局 CSS 层）
- `paper-grain`：SVG feTurbulence 噪点，opacity 5–8%，平铺于 `body::before`，z-index 低于内容、固定定位。
- `kraft-lines`：信纸淡横线（32px 间隔、1px `#D9C9A8` 60% 透明），用于信件编辑器与阅读页。
- 卡片 = "仿旧明信片"：`bg-kraft` + 圆角 12px + **细双线边框**（外 1px `#C9B48C`、内 inset 3px 1px `#C9B48C`/50%）+ 微泛黄渐变 + 角落邮戳装饰。
- 分隔线：不用实线。两种——①虚线"缝纫线"（`border-top: 2px dashed #B9A67F`）②手绘波浪 SVG 线（首页 section 间）。
- 阴影：无冷灰投影。统一暖纸影 `0 2px 8px rgba(107,74,50,.12), 0 12px 32px rgba(107,74,50,.08)`。

### 3.2 关键图形元素（实现为内联 SVG 组件库）

## 4. 动效系统

### 4.1 全局动效语法
- 缓动：`cubic-bezier(0.22, 1, 0.36, 1)`（easeOutQuint 感），时长 400–800ms；页面级 1000–1600ms。
- **禁用**：spring、bounce、elastic、shake。
- 滚动：Lenis（`lerp: 0.08`）+ GSAP ScrollTrigger；常规 section 入场统一规范：`y: 40→0, opacity: 0→1, duration: 0.8s, stagger: 0.12s, trigger at 85% viewport`。
- 性能：同屏动画元素 ≤8；纹理噪点静态；夜间灯晕用 CSS radial-gradient 不用 shader。

### 4.2 四个"签名动效"（全站复用，做成 hooks/组件）
1. **暖光呼吸 `<LampGlow/>`**：台灯/灯笼光晕 opacity 0.55↔0.85、scale 1↔1.04，3.2s 循环 ease-in-out；夜间模式亮度+30%。
2. **信封投递 `<EnvelopeDrop/>`**（写信提交）：信纸沿中线折起变信封（scaleY 1→0.35 + 上沿折角 clip-path）→ 滑向投递口（translateX + rotate -4°）→ 没入细长投信口（scaleX 1→0.6, opacity 渐隐）→ 投信口下沿灯一闪。全程 1.8s 一段式 GSAP timeline，结束触发路由跳确认态。
3. **牛奶箱开启 `<MilkBoxOpen/>`**（我的信件有未读回信时）：箱盖 rotateX 0→-70°（transform-origin 顶边，600ms）→ 信纸从箱口升起（y: 24→-8）→ 微光溢出。只自动播一次，之后 hover 可重播。
4. **纸面展开 `<PaperUnfold/>`**（信件阅读页进入）：信纸 scaleY 0.6→1 + 顶部向下"摊平"位移 + 邮戳盖章（scale 1.6→1, rotate -12°→-8°, opacity 0→1, 最后 200ms 加一层墨晕扩散）。

### 4.3 微交互
- CTA（邮戳朱）：hover 轻微下沉（y+1）+ 墨色加深 + 右下角邮戳纹理浮现；按下盖"已受理"半透明章。
- 商品卡：hover 卡片上浮 6px、暖光晕从卡片后渗出、商品图 1.03 倍缓慢推近（600ms）。
- 链接：hover 出现手绘下划线（SVG path draw 300ms）。
- Toast：从顶部飘下一张小纸笺（y: -16→0 + rotate 1°，500ms），木棕底奶油字。

## 5. 布局与响应式

- 容器：max-w 1120px（信件阅读页 720px 单列），左右 padding 24px（移动 16px）。
- 网格：商品货架 `grid-cols-2 md:3 lg:4`，gap 24；信件/故事卡 `md:grid-cols-2`。
- 断点：sm 640 / md 768 / lg 1024。移动优先。
- 导航：桌面顶部木质导航条（高 64px）+ 其下 32px 昼夜状态条；移动端折叠为木牌 logo + 汉堡（展开为全屏牛皮纸抽屉菜单，菜单项竖排）。
- 间距 scale：4/8/12/16/24/32/48/64/96（section 纵向节奏 64–96px）。

## 6. 共享组件

### 6.1 `<Navbar/>`
木棕底（`bg-wood` + 木纹 SVG overlay 8%），左侧 `<ShopSign/>`（点击回首页）；中间导航：商城货架 / 解忧信箱 / 示例信件 / 关于本店；右侧：搜索 icon（点击展开木牌下挂式搜索条）、牛奶箱 icon（带未读角标=未读回信数，苔绿圆点）、购物车 icon（角标=条目数）、用户笔名/「Kimi 登录」按钮。
**Animation**：滚动超过 80px 后导航条从 64px 收缩至 52px 并加深投影（300ms）；移动端抽屉菜单从右滑入（x: 100%→0, 450ms）+ 菜单项 stagger 60ms 淡入。

### 6.2 `<DayNightBar/>`（昼夜状态条）
导航下方通栏 32px：日间 `bg-kraft` 深木棕字「营业中 08:30–20:00 · 货架开放，欢迎咨询」+ 太阳/灯笼线稿；夜间 `bg-night` 奶油字「打烊后，信箱投递口开放 · 明早 8:30 牛奶箱取回信」+ 灯笼点亮发光。右侧永远是灯笼切换钮。
**Animation**：昼夜切换时状态条文字交叉淡入（400ms），灯笼点亮做 1 次呼吸。

### 6.3 `<Footer/>`
深夜蓝底（日间也用，作为"打烊后的店"隐喻），三栏：左=招牌小字与「提供商品订购服务，欢迎咨询」；中=导航；右=「写信给店主」入口 + 红豆面包+牛奶小插画。底部一行缝纫虚线 + 版权与"本店信件绝不窥视"隐私承诺。
**Animation**：红豆面包插画上方热气做 4s 循环上升淡隐（3 条 S 形路径 stagger）。

### 6.4 业务组件
`<ProductCard/>`（图+名+价+店主手记一句）、`<PostcardCard/>`（双线框明信片卡）、`<Postmark/>`、`<MilkBox/>`、`<CategorySeal/>`、`<PenNameChip/>`（可刷新随机笔名）、`<CountdownTag/>`（回信倒计时）、`<EmptyState/>`（牛奶箱插画+文案+CTA）、`<QuoteCarousel/>`、`<LetterPaper/>`（信纸容器：横线纹理+右上角邮戳+落款「浪矢杂货店」手写体）、`<ShopkeeperNote/>`（店主手记：手写体 + 左侧 2px 朱红竖线 + 微倾 -0.5°）、`<Modal/>`/`<Drawer/>`（shadcn 改造：牛皮纸底+双线框）、`<Protected/>`（未登录重定向 `/login?from=`）。

## 9. 依赖清单（实现参考）

`tailwindcss@3.4` · `gsap`（ScrollTrigger）· `framer-motion` · `lenis` · `shadcn/ui`（Dialog/Drawer/Tabs/Toast 改造为纸感皮肤）· Google Fonts（Ma Shan Zheng / Noto Serif SC / EB Garamond / Shippori Mincho B1）。无 Three.js 需求（氛围以插画+CSS 光晕实现，更贴合纸感）。

## 10. 全局文案语气（Tone of Voice）

- 自称「本店」/「店主」，称用户「你」；禁用电商促销话术（"疯抢""秒杀"），用「货架上寥寥的商品，但每一件都用纸包好了」。
- 系统提示样例：限流=「店主正在认真读上一封信，请稍后再来。」；空购物车=「篮子还空着，去货架上看看吧。」；未登录=「先进店来，写不写随你。」
- 信件落款固定手写体「浪矢杂货店」+ 日期邮戳。
